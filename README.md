# MoviePilot 自定义插件包

包含七个针对「订阅剧集追更」与「下载器维护」场景的自定义插件，解决国内影视平台数据与 TMDB 不一致导致的订阅问题，以及下载器数据文件的空壳种子 / 孤儿文件 / 站点已删除死种 / 跨站独苗种子 / 订阅剧集过期集的清理维护。

> 作者信息默认为 `Finn`；如需以自己的名义发布，请修改源码中的 `plugin_author` 与 `author_url` 两处字段（共 7 个插件文件）。

## 插件列表

### 1. 订阅完结交叉校验（SubscribeCompletionCrossCheck）v1.6

**解决痛点**：TMDB 对国产剧/国漫的总集数标注经常滞后（例如某剧 TMDB 只标 12 集，实际有 25 集），导致 MoviePilot 在剧集尚未完结时就判定"已完结"、停止下载后续集数。

**核心能力**：
- **实时守卫**：订阅被判定完结、归档删除之前，交叉校验以下数据源：
  - 豆瓣：总集数 + 平台连载状态（"更新至X集"，聚合自优酷/腾讯视频/爱奇艺等国内播放平台）
  - Bangumi：总集数（动漫收录好）
  - 任一源显示剧集未完结 → 自动否决完结，扩展订阅总集数，继续追更
- **每日兜底扫描**（默认每天 09:00）：扫描近期已完结的订阅历史，发现误完结的自动重建订阅
- **源不可用容错**：豆瓣/Bangumi 接口异常时挂起完结判定、自动重试；连续 N 天不可用才放行并通知，避免误完结和死挂
- **国内剧以豆瓣为准**（v1.4）：豆瓣显示已完结而 TMDB 集数虚高时，自动收缩订阅总集数促使其正常完结归档；国外剧以 TMDB 为准不干预
- **分季条目防误判**（v1.5）：豆瓣集数与订阅集数差距过大时判定为分季/拆分条目，自动跳过，保护连载年番不被误完结
- **搜索兜底**（v1.6）：豆瓣 tv_search 搜不到部分新版条目（如《将夜》2026版）时，改用聚合搜索兜底，仅取电视剧条目，解决漏处理
- **通知**：飞书 Webhook 或系统消息，内容含校验证据（各源集数）

**配置项**：启用、Bangumi 校验开关、兜底扫描时间/范围/条数、源不可用挂起天数、无总集数缓冲集数、飞书 Webhook、通知前缀。

**依赖**：MoviePilot v2.15.6+；容器内需可访问豆瓣接口（MoviePilot 内置模块）与 api.bgm.tv（通过 curl 子进程）。

### 2. 订阅日历监控（SubscribeCalendarMonitor）v1.2

**能力**：每日定时检查"当日播出"的订阅剧集是否已下载入库并发送通知（如飞书日报）。使用 TMDB 播出日历 + 媒体库文件状态比对。

**配置项**：启用、检查时间（Cron）、仅有缺失时通知、飞书 Webhook、通知前缀、立即运行一次。

**依赖**：MoviePilot v2（使用内置 TmdbChain / SubscribeChain）。

### 3. 种子文件清理（TorrentFileCleaner）v1.3

**解决痛点**：手工清理或迁移媒体文件后，下载器中残留“数据文件已被删除”的空壳种子任务，占用下载器资源、影响做种统计。

**核心能力**：
- 定时扫描 **Transmission + qBittorrent** 全部种子，逐一检查数据文件/目录是否仍存在于下载目录
- 数据文件不存在的“空壳种子”自动移除任务（**仅删任务，不删文件——文件已不存在**）
- Transmission：download_dir + name 检查，兼容 `.part` 后缀
- qBittorrent：content_path / save_path + name 双路径检查，兼容 `.!qB` 后缀
- **每轮必发通知**（v1.3）：无论是否有清理结果，均发送本轮执行回执（含各下载器扫描统计：种子数/清理数/状态），无删除时也能确认本轮已执行
- **按下载器独立开关**（v1.2）：配置页动态列出全部已配置下载器，每个下载器可独立选择是否执行清理（如多下载器分工场景可排除某些下载器）
- **每下载器独立路径映射**（v1.2）：映射配置从全局改为按下载器粒度（如仅 qb-other 配 `/downloads=/media`）；插件级映射优先，未配置时自动继承 MoviePilot 下载器设置中的系统级路径映射
- **全量不可达保护**（v1.1）：某下载器全部种子路径均不存在时判定为挂载问题，跳过该下载器并通知，**防止批量误删**
- 飞书 Webhook 通知清理结果

**配置项**：启用、执行周期（Cron，默认每 6 小时）、发送通知、各下载器独立开关、各下载器独立路径映射、飞书 Webhook、通知前缀、立即运行一次。

**依赖**：MoviePilot v2（使用内置 DownloaderHelper）；MoviePilot 容器需能访问下载器的文件路径（共享挂载或配置路径映射）。

### 4. 孤儿文件清理（OrphanFileCleaner）v1.6

**解决痛点**：删除种子时保留文件、手工迁移、中断下载清理种子等场景，会在下载数据目录留下“有数据文件、但已无任何种子引用”的孤儿文件，占用存储空间。

**核心能力**：
- 收集全部下载器（Transmission + qBittorrent）种子的内容根路径作为引用集合，扫描用户配置的数据文件目录
- 找出磁盘存在但**任何下载器都无种子引用**的孤儿文件/目录（跨下载器去重，避免误判其他下载器正在做种的内容）
- 插件详情页**按文件夹分类**展示孤儿列表（路径/类型/大小），每条带**复选框**，可勾选后**批量删除勾选项**，也可删除全部；每个分类组带**总复选框**（一键选中/取消本组）与**删除本组全部**按钮
- **删除机制**：默认移入回收站目录（可恢复），可选彻底删除；删除前校验路径位于扫描目录范围内
- **硬链接检测**：对孤儿文件检查硬链接（nlink>1），在搜索范围内找出同 inode 的所有路径并标记列出，提示删除可能影响其他硬链接文件
- 支持下载器容器路径映射（如 `/downloads=/media`）
- 飞书/系统通知扫描与处理结果

**配置项**：启用、数据文件目录（每行一个）、下载器路径映射、删除机制（回收站/彻底）、回收站目录、硬链接检查开关、硬链接额外搜索目录、通知。

**版本历史**：v1.0 初始版（列表展示+逐条/全部删除）；v1.1 按文件夹分类+复选框勾选+批量删除勾选项；v1.2 硬链接检测与地址标记；v1.3 组级总复选框+删除本组全部；v1.4 修复页面事件不生效（API 改 GET）+ 勾选状态联动显示；v1.5 勾选内存化+页面轻量化，消除操作闪烁感；v1.6 详情页重新排版（状态摘要/按钮分级/组头横条统计/四列对齐/勾选背景标识）。

**依赖**：MoviePilot v2（使用内置 DownloaderHelper）；需与下载器共享存储（路径映射或相同挂载）。

### 5. 站点已删除种子清理（SiteDeletedTorrentCleaner）v1.6

**解决痛点**：站点种子被删除/失效（站点清种、违规删除、Tracker 失效）后，下载器中仍保留对应死种任务，占用做种资源、影响做种统计。

**核心能力**：
- **判定依据**：读取每个种子的 tracker 报错消息（qBittorrent tracker `msg` / Transmission `lastAnnounceResult`），命中关键词（如 `torrent not found`、`unregistered`、`not registered`、`不存在`、`已删除` 等）即判定为“站点已删除”，关键词可配置
- **扫描范围**：自动遍历 MoviePilot 全部已配置下载器，另支持**自定义下载器**（不在 MoviePilot 中的 qBittorrent/Transmission，按 `类型|地址|端口|用户名|密码` 填写）
- **界面交互**：展示死种列表（名称/大小/进度/站点/tracker 报错），单条勾选、组内全选、一键全选；删除单个 / 删除选中 / 删除全部 / 清空结果
- **站点识别**（v1.2/v1.3）：按 tracker 域名匹配 MoviePilot 站点管理站点名显示（如「馒头/家园/观众」，匹配不到显示域名）；qB 批量查询 trackers 偶发失败时自动重试并回退（RPC → torrent 字段 → 磁力链 tr= 参数），站点不再丢失
- **按站点分组**（v1.4）：同一站点跨下载器的死种聚合展示（组头显示站点名与各下载器分布统计，如 馒头:12 / qb-mp:3），组级全选/删除本组按站点精确过滤；展示分组方式可切换按站点/按下载器
- **误删恢复**（v1.6）：删除种子前自动备份到回收站——qB 导出 .torrent 文件（完整备份）、TR 记录磁力链（均含原保存路径）；插件页支持一键恢复（暂停添加→重新校验数据→启动，删了数据文件的会自动重新下载）、单条清除备份、一键清空；配置页可关闭备份
- **删除行为**：默认仅删任务保留文件；可配置「允许删除数据文件」并带**辅种保护**——若数据文件仍被其他种子做种则不删数据文件，仅当无其他种子辅种时才连同数据文件删除
- **触发方式**：页面手动「扫描死种」+ 配置 cron 定时扫描（可开启「定时扫描后自动删除」）
- **通知**：飞书 Webhook 或系统消息

**配置项**：启用、执行周期、允许删除数据文件、定时后自动删除、展示分组方式、自定义下载器、tracker 判定关键词、删除前备份开关、回收站备份保留天数（超期自动清理，0=永不清理）、飞书 Webhook、通知前缀、立即运行一次。

**依赖**：MoviePilot v2（使用 DownloaderHelper + qbittorrentapi / transmission-rpc 获取 tracker 状态）。

### 6. 跨站独苗种子清理（CrossSeedCleaner）v1.8

**解决痛点**：同一内容只在一个站点做种（独苗），该站删种/跑路即内容全失，抗风险能力为零；反过来，已有 2 站以上做种的内容，其中某站的死种即可安全清理释放空间。

**核心能力**：
- **独苗判定**：按内容聚合分组（种子名称 / 数据路径两种方式，跨下载器），统计该内容在哪些站点有做种：仅 1 站 = 独苗清理候选，≥2 站自动保留（跨站保流）；同名不同发布（如 WEBRip 与 WEB-DL）天然分组隔离互不干扰
- **双下载器支持**：Transmission（RPC 直连一次拉取全部种子）+ qBittorrent（并发抓 trackers，自动过滤 DHT/PEX/LSD 伪 tracker）；支持 MoviePilot 已配置下载器与自定义下载器（`类型|地址|端口|用户名|密码`）
- **保护规则**：含未完成种子的组整体跳过（下载/校验中不删）；保护站点白名单（多选下拉，选项自动读站点管理）；保护关键词；累计上传量阈值（阈值 0 = 仅清理从未上传过的种子，正常数值 = 组内累计上传≥N GB 整组保留）
- **安全删除**：删除前自动备份到回收站——qB 导出 .torrent 文件、TR 记录磁力链（均含原保存路径），支持一键恢复（暂停添加→重新校验数据→启动）；数据文件辅种保护：数据仍被删除范围之外的种子引用时自动降级为仅删任务；删数据文件默认关闭，需在配置页显式开启；分批删除快照落盘备查
- **整理联动**（v1.7）：删除数据文件的种子按 `download_hash` 精确匹配 MoviePilot 转移记录，同步删除媒体库硬链接文件与转移记录；媒体文件带**双重保护**——目标文件仍被其他转移记录（其他来源整理共享）指向或硬链接数 >1 时只删记录不删文件，外部存储（非 local）不动文件；删除后自动向上清理空目录；仅删任务（数据保留）的种子不触发
- **信息展示**（v1.5–v1.8）：每条种子带站点名标签、文件级小标签（单集种子显示实际文件名如 S01E05.mkv，整季种子不显示）、最新上传日期（TR `activityDate` / qB `last_activity`）与累计已传量；结果组按「组内最新上传时间」排序（默认旧→新，最久未传/从未上传的组排最前便于优先决策，一键切换新→旧）；**双视图**——按内容组或跨组按已配置下载器分组展示（组头带种子数/独苗组数/已勾选统计），一键切换，排序方向在两种视图下均生效
- **通知**：删除通知按站点汇总清理数量与释放空间（删数据/仅删任务分开计）；飞书 Webhook 或系统消息
- **触发方式**：页面手动「扫描分析」+ Cron 定时扫描（可开启「定时扫描后自动清理」，不开启则仅分析通知）

**配置项**：启用、允许删除数据文件、同步清理媒体库硬链接与转移记录、定时后自动清理、删除前备份开关、含未完成种子的组跳过、内容聚合方式、执行周期（Cron）、累计上传保护阈值GB、保护站点（多选）、保护关键词、自定义下载器、飞书 Webhook、通知前缀、立即运行一次。

**版本历史**：v1.0 首发（TR/QB 双下载器聚合+独苗判定+全套保护+回收站备份）；v1.2 站点维度删除统计；v1.3 站点名称对齐站点管理+插件更名+保护站点多选下拉；v1.4 保护站点空值迁移+上传阈值语义修正；v1.5 结果页新增最新上传时间列；v1.6 条目站点名标签+按最新上传时间排序（升降序一键切换）；v1.7 整理联动——删数据时同步清理媒体库硬链接与转移记录（共享引用/链接数双重保护、空目录清理、统计并入通知）；v1.8 条目文件级标签（区分同组同名不同集）+ 按下载器分组视图（一键切换）。

**依赖**：MoviePilot v2（DownloaderHelper + Transmission RPC / qbittorrentapi）。

### 7. 订阅剧集自动清理（SubscribeEpisodeCleaner）v1.6

**解决痛点**：订阅一部电视剧后，随着每周更新已下载剧集越攒越多，占用大量存储空间；同时若只是手工删掉旧集，MoviePilot 会因媒体库比对出该集缺失而**通过订阅再次补下**。

**核心能力**：
- **指定订阅（多选）**：配置页多选下拉选择要管理的电视剧订阅，可同时管理多部，各订阅独立计算保留窗口；旧单选配置自动迁移
- **按集号保留最新 N 集**：扫描该订阅对应下载器中的剧集种子，解析集号，只保留集号最大的 N 集；更早的剧集全部删除（含跨集号种子如 `S01E01-E05` 的整包覆盖判定）
- **删数据 + 退出做种**：删除的剧集种子连同数据文件一起从下载器移除（Transmission RPC 直连 / qBittorrent 均支持），释放磁盘与做种资源
- **防止重复下载（核心）**：删除的集号写入订阅 `note`（已下载集 JSON 列表）。MoviePilot 的搜索与刷新通道都会把 `note` 中的集号当作"已下载过"而从缺失集中剔除，因此这些旧集不会再次通过订阅重新下载（而非只是改缺失计数）
- **媒体库硬链接联动**：删除数据文件的种子按 `download_hash` 精确匹配转移记录，同步清理媒体库硬链接文件与转移记录；媒体文件带保护（外部存储不动文件），删除后自动向上清理空目录；**等待异步删除（v1.3）**：qb 删除数据文件后等待源文件从磁盘消失再判硬链接数，避免记录删了但文件欠账
- **辅种级联删除（v1.3）**：共享同一数据文件的辅种/重复种子（如 IYUU 辅种的另一站发布）一并删除并备份，不再因数据被范围外种子引用而卡住；**旧集媒体端清理（v1.3）**：保留窗口外旧集（含种子已不在下载器的历史集）按集号清理媒体文件（视频+nfo/jpg 附属）与转移记录
- **安全删除**：删除前回收站备份（qB 导出 .torrent / TR 记录磁力链，支持恢复）；**回收站过期自动清理（v1.6）**——备份按可设保留天数（默认 30 天，0=永不清理）自动清理过期条目与 .torrent 文件，防止备份无限堆积；定时任务/手动扫描/执行清理时自动顺带维护并计入回执通知，另有 `/clean_recycle` API 可手动触发；含未完成（下载/校验中）的剧集种子自动跳过；数据仍被删除范围之外种子引用时整条保留
- **归属匹配（三层）**：① 订阅名 + 订阅 keyword；② **自动挖掘下载历史别名**——按 tmdbid/标题归属把该订阅历史下载种子的发布名（去季集后缀）作为匹配词，中文订阅可命中英文发布名（如「一念永恒」→ A Will Eternal）；③ **download_hash 精确命中**——下载器种子 hash 与历史记录一致即归属该订阅；另可配置额外匹配词；支持季过滤（配置季或订阅季）
- **完结自动全清（v1.5）**：检测到订阅完结归档（转入 subscribehistory）后开始计时——完结语优先取 MP「已完成订阅」消息时间（无则首次检测时间）；从完结日起保留可设天数（默认 7 天），期间发到期预告，到期自动全部清理：该书全部种子（含辅种级联）、媒体文件（含保留集、海报/nfo 附属）、转移记录，并自动从插件订阅列表移除，发完结通知；完结清理可关闭（改为仅提醒）；插件自动快照订阅身份（name/year/season/tmdbid），订阅归档后仍可正确追溯匹配
- **通知（v1.4 完善）**：执行清理后必发**执行回执**（删除种子数含辅种级联、释放空间、整理联动与旧集清理统计、各订阅保留窗口、防重下写入提示）；手动扫描后发**扫描回执**（各订阅保留窗口与待清理统计）；定时自动清理同样发执行回执；通道为飞书 Webhook 或 MP 系统消息

**配置项**：启用、指定订阅（多选下拉）、保留最新几集、完结后自动全清开关、完结后保留天数、季（可选）、额外匹配词、执行周期（Cron）、删除数据文件并退出做种、同步清理媒体库硬链接与转移记录、删除前备份开关、含未完成种子跳过、定时自动清理、飞书 Webhook、通知前缀、自定义下载器、立即运行一次。

**版本历史**：v1.0 首发；v1.1 多选订阅；v1.2 英文发布名/整季包匹配修复；v1.3 辅种级联+旧集媒体清理+异步等待；v1.4 执行/扫描后必发回执通知；v1.5 完结自动全清（完结日+可设宽限期→到期清空）与订阅身份快照；v1.6 回收站过期备份自动清理（保留天数可设，0=永不清理，防备份无限堆积）。

## 安装方式

### 方式一：zip 本地安装（最简单）

1. 解压本包，或在 MoviePilot 插件页面使用「本地安装/上传 zip」
2. 若不支持 zip 安装：将 `subscribecompletioncrosscheck/`、`subscribecalendarmonitor/`、`torrentfilecleaner/`、`orphanfilecleaner/`、`sitedeletedtorrentcleaner/`、`crossseedcleaner/` 和 `subscribeepisodecleaner/` 七个目录
   直接复制到 MoviePilot 容器的 `/app/app/plugins/` 下
3. 在 MoviePilot 的 `systemconfig` 表（PostgreSQL）的 `UserInstalledPlugins` 配置中
    追加插件类名：`SubscribeCompletionCrossCheck`、`SubscribeCalendarMonitor`、`TorrentFileCleaner`、`OrphanFileCleaner`、`SiteDeletedTorrentCleaner`、`CrossSeedCleaner`、`SubscribeEpisodeCleaner`
4. 重启 MoviePilot 容器，插件市场即可看到插件并配置

### 方式二：GitHub 插件仓库（推荐，支持自动更新）

1. 将本包内容推送到 GitHub 仓库（根目录含插件目录与 package.json 即可）
2. MoviePilot → 设置 → 插件 → 自定义插件源，添加仓库地址（`https://github.com/你的用户名/仓库名`）
3. 插件市场即可搜到并一键安装，后续插件更新可从市场拉取

## 注意事项

- 源码不含任何个人配置（Webhook、Token 等均在安装后由配置页面填写）
- 豆瓣数据接口为 MoviePilot 内置模块，无需额外 Key；Bangumi 无需 Key
- 兼容性：基于 MoviePilot v2 API 开发；MoviePilot v3（新架构）可能需要适配
